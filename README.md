# 무석연합민턴 🏸

무석연합교회 배드민턴 모임 앱 (스마트폰 세로 화면 기준)

## 기능
- **코트비 엔빵**: 날짜 선택 → 코트비(기본 276위안) / 콕 구매(기본 140위안) → 참석 체크(2시간 = 1명, 1시간↓ = 0.5명) → 정산
  - 자녀는 보호자에게 합산 청구 — 예) `문명국(본인+아들) 92.4위안`
  - 정산 후 `수정` → 다시 `엔빵 정산`, `결과 복사`로 단톡방 공유
- **모임 기록**: 날짜별 정산 기록, 눌러서 보기 · 수정 · 삭제
- **멤버**: 추가 · 편집 · 삭제, 자녀는 "정산하는 사람(보호자)" 지정

## 개발
```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 빌드 (Vercel: Vite 프리셋 그대로 배포)
```

데이터는 현재 각 기기 브라우저(localStorage)에 저장됩니다. 여러 사람이 같은 기록을 보려면
`src/storage.js`를 Supabase/Firebase로 교체하면 됩니다.
